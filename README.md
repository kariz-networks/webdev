# Joseph Kariuki — Developer Portfolio

A responsive developer portfolio built with HTML, CSS, and JavaScript.

## Add your profile photo

The profile image is `joseph-kariuki.png` in this folder. To use a different picture, replace that image file with your new photo, keeping the same filename.

## Resume

`Joseph-Kariuki-Resume.pdf` is the resume linked from the contact section. It summarizes Joseph's IT studies at Kirinyaga University, developer skills, and portfolio projects. Add study dates or further experience when available, and update the PDF if those details change.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.
